# Rafael Panel v63

Rafael Panel v63 is based on the MHSanaei/3x-ui v2.9.2 codebase with expanded database and management features. It bundles the matching Rafael Xray fork compiled from the source in this repository.

## Effective quota display and cutoff

Inbound client tables and mobile cards now display the persisted effective traffic allowance, including the remaining amount, progress, warning state, and depleted state. When a traffic record is absent, the display derives the initial allowance from the nominal quota and configured coefficient. This keeps a fresh 0.2 GB allocation at coefficient 2 displayed as about 0.1 GB, instead of showing the nominal 0.2 GB beside a progress bar calculated from a different cap. Previously granted allowance is preserved when only the coefficient changes; a reset starts a new allowance with the current coefficient.

Quota samples run every 2 seconds, and the restart watcher checks every second. When quota enforcement removes a user, existing sessions are therefore cleared without waiting up to the previous 30-second restart interval. Traffic already counted between samples or in flight during disconnect may still produce a small overrun; a byte-perfect cutoff cannot be claimed from periodic counters alone.

## Performance visibility

HTTP request timing and major traffic-poll stages emit `PERF` warnings when slower than 500 ms by default. The HTTP log records the route template, method, status and response size without raw URLs, query strings, client email addresses or credentials. Traffic reconciliation also reports bounded stage names and object counts. Set `RAFAEL_PERF_SLOW_MS` to tune the threshold in milliseconds or `0` to disable it. Client/traffic matching in reconciliation uses indexed lookups instead of nested scans.

This instrumentation is intended to identify bottlenecks during real use. The package build does not measure production latency or certify runtime behavior.

## Client traffic coefficients

Each client stores its nominal traffic amount in its inbound settings and its current effective allowance in the existing client traffic record. The coefficient applies to newly added quota and to a reset. Editing the coefficient alone leaves the current effective allowance unchanged, so previously consumed traffic is never retroactively recalculated. A coefficient of `0` or `1` means normal 1:1 allocation.

The client edit modal stores and displays the configured coefficient. Client lists show a `Factor ×N` tag; a missing or zero coefficient is shown as `Factor ×1`.

Example: a new 1 GB client with coefficient `2` receives 500 MB. If the client has used that 500 MB and the nominal quota is raised from 1 GB to 2 GB with coefficient `2`, the effective cap increases by 500 MB, making another 500 MB available. Resetting starts a new cycle from 2 GB / 2, which is 1 GB. Reseller assignment checks and multi-link quota displays use the effective allowance.

## Multi-link IP limit

The forked Xray process tracks active IPs by logical client identity. Client aliases with the same multi-link `SubID` share one counter and the strictest positive IP cap across the aliases. This works when the related inbounds run in the same Xray process. Separate Xray processes, including inbounds hosted on different nodes, do not share live session state; the limit is therefore per process/node and is not a global cross-node device cap.

Multi-link creation and editing now expose an IP-limit enable switch and maximum-IP value. Turning the switch off sends an unlimited value while retaining the entered maximum for when it is turned back on.

## Linux amd64 install

Install/upgrade from the GitHub installer:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Rafael7277/rafael-panel/main/install.sh) v63
```

Flat install from the self-contained archive:

```bash
curl -fL -o rafael-linux-amd64.tar.gz https://github.com/Rafael7277/rafael-panel/releases/download/v63/rafael-linux-amd64.tar.gz
curl -fL -o rafael-linux-amd64.tar.gz.sha256 https://github.com/Rafael7277/rafael-panel/releases/download/v63/rafael-linux-amd64.tar.gz.sha256
sha256sum --check rafael-linux-amd64.tar.gz.sha256
tar -xzf rafael-linux-amd64.tar.gz
cd rafael
bash ./install-local.sh
```

The package includes the panel binary, the matching forked Xray binary, the matching Xray source archive, GeoIP/GeoSite data, installer/updater scripts, notices, licenses, and SHA-256 sidecars. No separate Xray download is required.
