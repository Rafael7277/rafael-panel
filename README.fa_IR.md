# پنل رافائل

پنل مدیریت Xray رافائل از [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) توسعه یافته است. نسخهٔ پایه در `config/version` برابر **2.9.2** است. رافائل مدل داده و امکانات پنل را گسترش می‌دهد و مجوز GPL-3.0 را حفظ می‌کند؛ جزئیات در [NOTICE](./NOTICE) و [LICENSE](./LICENSE).

## امکانات اصلی

- **محدودیت واقعی IP کلاینت:** در زمان اجرا و داخل Xray فورک‌شدهٔ رافائل اعمال می‌شود و سابقه و مهلت ارفاقی IP را دارد. باینری هماهنگ Xray داخل بسته است.
- **پنل نمایندگی:** حساب نماینده، تعیین اینباندهای مجاز و بخش‌های قابل‌دسترسی، سهمیهٔ کاربر و ترافیک، مسیر پورتال و کنترل چرخهٔ عمر.
- **بالانسر هوشمند تطبیقی:** سلامت و موفقیت اوتباندها را پایش می‌کند، عضو ناسالم را موقتاً از انتخاب خارج می‌کند و پس از بازیابی برمی‌گرداند. هدف کاهش خطای مسیریابی و packet loss است؛ صفرشدن packet loss قابل تضمین نیست.
- **مدل دادهٔ توسعه‌یافته:** قابلیت‌های نمایندگی، محدودیت IP، چرخهٔ عمر، سهمیه‌ها و مدیریت پنل به پایهٔ نسخهٔ 2.9.2 اضافه شده‌اند.
- **نصب راهنما‌دار:** انتخاب پورت، ساخت وب‌پچ خصوصی، دامنه یا IP و انتخاب Let's Encrypt، گواهی موجود یا HTTP بدون SSL.

## نصب

روی Debian/Ubuntu Linux amd64 و با دسترسی root اجرا شود. بستهٔ پنل، Xray فورک‌شده را هم دارد و دانلود جداگانه لازم نیست.

آخرین نسخهٔ عمومی:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Rafael7277/rafael-panel/main/install.sh)
```

نسخهٔ ثابت v59:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/Rafael7277/rafael-panel/main/install.sh) v59
```

نصب‌کننده SHA-256 را بررسی می‌کند. نصب تازه از مسیر تخت /usr/local/rafael استفاده می‌کند. نصب موجود با updater خط فرمان رافائل ارتقا می‌یابد و دیتابیس و تنظیمات را حفظ می‌کند؛ کاربر ارتقای موفق v58 به v59 از طریق CLI را تأیید کرده است.

نصب‌کننده پورت تصادفی یا انتخابی، دامنه/IP، وب‌پچ خصوصی و SSL اختیاری را تنظیم می‌کند. برای Let's Encrypt HTTP-01، پورت عمومی TCP 80 باید به listener چالش برسد.

## انتشار

هر push به main بستهٔ Linux amd64 پنل را با Xray فورک‌شده می‌سازد و به‌صورت GitHub Actions Artifact می‌گذارد. push تگ v59 علاوه بر ساخت بسته، Release شماره‌دار می‌سازد. بسته، Xray مستقل، سورس هماهنگ Xray و SHA-256ها در Release قرار می‌گیرند.

ساخت محلی Windows با Go و tar: `./build-release-v59.ps1`
