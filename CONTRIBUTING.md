# Contributing

Thanks for helping improve Rafael Panel. Please keep changes focused and include enough context for maintainers to review them.

## Before opening a pull request

- Explain the user-visible behavior or bug being addressed.
- Keep credentials, production configuration, database dumps, local build outputs, and private operational notes out of commits.
- Update user documentation when installation or runtime behavior changes.
- Include the relevant validation performed and any remaining limitations.

## Pull requests

Use a clear title, describe the change and its impact, and link related issues where applicable. Changes to the bundled Xray fork must include the source provenance and updated integrity metadata required by the release workflow.
